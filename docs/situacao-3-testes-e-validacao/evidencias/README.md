# Evidências dos testes

Esta pasta guarda o que comprova os testes feitos com pessoas:

- `respostas-dos-5-testadores.pdf`: as cinco respostas do formulário, exportadas do Google Forms.
- `prints/`: capturas de tela dos erros encontrados e das correções, com o nome do arquivo indicando o defeito (por exemplo `D01-antes.png` e `D01-depois.png`).
- `resultado-dos-testes-automaticos.txt`: saída do comando `python -m pytest`, com data.

Enquanto os testes não acontecem, a pasta fica só com este arquivo.
