# Evidências dos testes

Esta pasta guarda o que comprova os testes feitos com pessoas:

- `resposta-raila.pdf`: resposta individual da testadora Raila, exportada do Google Forms (16/11/2026).
- `prints/`: capturas de tela dos erros encontrados e das correções, com o nome do arquivo indicando o defeito (por exemplo `D01-antes.png` e `D01-depois.png`).
- `resultado-dos-testes-automaticos.txt`: saída do comando `python -m pytest`, com data.

O resultado dos testes automáticos e a resposta da Raila já estão nesta pasta. A resposta da Marcela e os prints entram quando forem exportados; nenhum defeito foi corrigido nesta entrega, então não há prints de antes e depois.
